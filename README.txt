CRECHE TIA ROSA — SITE INICIAL
================================

Arquivos:
- index.html
- css/style.css
- js/script.js

Como abrir:
1. Extraia o ZIP para uma pasta.
2. Abra a pasta no VS Code.
3. Abra index.html no navegador (ou use a extensão Live Server).

O que já está incluído:
- Layout responsivo para computador e celular.
- Paleta colorida inspirada no universo visual do Objetivo: azul, amarelo e vermelho.
- Animações de entrada ao rolar, elementos flutuantes, efeitos nos cartões e botões.
- Menu mobile, botão de voltar ao topo e links de telefone/e-mail/mapa.
- A seção de gratuidade não foi incluída.

IMPORTANTE SOBRE REDES SOCIAIS:
- O WhatsApp usa o telefone público encontrado para a creche (0538-36-3225), convertido para o formato internacional. O link só abrirá uma conversa se esse número tiver WhatsApp ativo.
- Facebook e Instagram estão configurados como buscas pelo nome da escola, porque não foi possível confirmar perfis oficiais. Para apontar diretamente para os perfis corretos, altere CONFIG.facebook e CONFIG.instagram no início de js/script.js.
- Confira telefone, endereço, e-mail e todas as informações antes de publicar.

A identidade visual é uma interpretação original inspirada nas cores e no estilo alegre do site de referência, não uma cópia do site Objetivo Sorocaba.
